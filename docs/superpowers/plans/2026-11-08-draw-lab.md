# Lucky Draw Lab Implementation Plan

> Implement inline using the executing-plans workflow.

**Goal:** Interactive shared-prize probability explorer with cumulative outcomes in the chart.
**Architecture:** Pure math module, worker for simulations/comparisons, React dashboard and SVG charts.
**Tech Stack:** React, Vite, Node test runner, Playwright, Lucide.
**Spec:** docs/superpowers/specs/2026-11-08-draw-lab-design.md

## Constraints and review focus
- One prize per account, shared finite pool, equal independent per-draw probability.
- Label random allocation assumptions and Monte Carlo uncertainty.
- P(Y > 1) includes 2 and higher; never confuse it with P(Y >= 1).
- Check zero/certain probability, zero prizes/participants/draws, oversubscribed pools, large populations, equal draw budgets, rapid input changes, and narrow screens.
